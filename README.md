# React Exercises

Repositório destinado ao estudo completo e progressivo de React, acompanhando o [Roadmap de React](https://roadmap.sh/react). O objetivo deste projeto é passar por todos os conceitos fundamentais e avançados do ecossistema React.

## Visão Geral de Estudos (Roadmap)

Abaixo estão os principais tópicos que compõem a jornada de aprendizado deste repositório:

*   **Fundamentos e Ferramentas**
    *   CLI Tools (Vite)
*   **Componentes (Components)**
    *   Functional Components
    *   JSX, Props vs State
    *   Conditional Rendering, Composition
*   **Renderização (Rendering)**
    *   Component Lifecycle
    *   Lists and Keys, Refs, Events
*   **Hooks**
    *   Basic Hooks (useState, useEffect, useContext)
    *   Common Hooks (useRef, useMemo, useCallback)
    *   Custom Hooks
*   **Roteamento (Routers)**
    *   React Router, TanStack Router
*   **Gerenciamento de Estado (State Management)**
    *   Context API, Zustand, Redux, etc.
*   **Estilização (Writing CSS / UI Libraries)**
    *   CSS Modules, Tailwind CSS
    *   Component Libraries (Shadcn UI, Material UI)
*   **Comunicação com APIs (API Calls)**
    *   Axios, Fetch, React Query, SWR
*   **Testes (Testing)**
    *   Vitest, Jest, React Testing Library, Cypress
*   **Frameworks e Tópicos Avançados**
    *   Next.js
    *   Types & Validation (TypeScript, Zod)
    *   Forms (React Hook Form)
    *   Performance, Suspense, Error Boundaries
